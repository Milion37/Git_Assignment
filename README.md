# Git and GitHub Assignment

## Project Description
This project demonstrates the basic use of Git and GitHub.
It contains a Python script with sample health data.

## Project Contents
- `sample_data.py`: Displays four imaginary health records.
- `README.md`: Describes the project and its contents.

## Tools Used
- Git
- GitHub
- Python

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run `python sample_data.py`.

## Learning Objectives
- Create a local Git repository.
- Track and commit changes.
- Create a remote GitHub repository.
- Push local changes to GitHub.
- Use Markdown to document a project.
## Git Workflow
The basic Git workflow is:
1. Add changes.
2. Commit changes.
3. Push changes to GitHub.
